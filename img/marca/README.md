# Identidad CUC

Referencia consultada el 22 de octubre de 2026: [página institucional](https://www.cuc.edu.co/imagen-institucional-unicosta) y [Manual resumido de marca, publicado en agosto de 2024](https://www.cuc.edu.co/wp-content/uploads/2024/08/CUC-LOGO-MANUAL-RESUMIDO-1.pdf).

- `cuc-logo-vector.pdf`: imagotipo horizontal rojo, extraído como vectores de la página 3 del manual, con margen blanco. No se reconstruyeron letras ni se alteraron proporciones o colores.
- `cuc-logo.png`: rasterización de ese mismo recurso para Word.
- `cuc-logo-vertical.png`: recurso oficial descargado de https://www.cuc.edu.co/wp-content/uploads/2024/03/logo_cuc_vertical.png; conservado como referencia.
- Acento principal: Auburn `#A3161A`. Apoyo: dorado `#C9A227`, gris `#595959`, plata `#CCCCCC`. El logo rojo se utiliza sobre fondo blanco, separado de fotografías y gráficos.
- Tipografía institucional: Red Hat Display. Archivos estáticos derivados de las fuentes variables oficiales de Google Fonts, pesos 400/500/700 e itálica 400, en `docs/latex/fuentes/`, con licencia OFL incluida.

La composición del trabajo es propia; estos archivos no implican una aprobación institucional del diseño electrónico. Se mantienen los colores de identificación de señales en las figuras técnicas.
